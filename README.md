# 处理步骤
1. 图像预处理:首先进行图像的预处理，去除图像采集时的噪点
2. 提取感兴趣区域（ROI）:用边沿检测的方式找到丝饼的内外圆（纱管和丝饼边缘），确定一个圆环形的检测区域。
3. 极坐标变换:对图像进行极坐标展开，将圆环展开成矩形图像，并且转换到梯度空间
4. 缺陷识别与标记:在梯度空间的图像上，计算两个关键特征——信息熵和能量，通过设定阈值把缺陷区域分割出来。
5. 后处理:最后用形态学处理（比如去除一些微小的噪点、填充缺陷内的空洞），得到最终的检测结果。

# 现在完成的工作
- 进行了图像预处理

传统目标检测算法：
HOG/LBP + SVM
针对压痕/跳丝：使用 HOG (方向梯度直方图)。
原理：HOG 对边缘的方向非常敏感。正常的纱线是水平纹理，HOG 特征会集中在水平方向；而跳丝和压痕会产生垂直或杂乱的梯度方向。

针对脏物/表面质感：使用 LBP 、GLCM 。
原理：LBP 极其擅长描述微观纹理。脏物平滑的黑色区域与纱线的粗糙纹理在 LBP 编码上有巨大差异。

现在确定了使用传统目标检测算法；对每种疵点单独分析，找到其适合的特征提取方式，对需要的特征提取方式进行汇总，然后再用SVM分类。

注意：使用多种特征提取方式，但特征向量会变得非常长。
在喂给 SVM 之前，先用 PCA (主成分分析) 进行降维。（可以不直接对全图提特征，例如：中间纹理区：重点提取 LBP + 均值特征，外圈边缘区：重点提取 HOG 特征。）
